Drift

Break the scroll, gently.

Drift is an Android app for stepping away from short-video feeds with gentle reminders and staged friction, not hard blocking.

Core short-video detection and leave-flow handling run on-device. The current release may also send limited product analytics so the app can be improved.

What Drift does

  • Identifies supported short-video pages.
  • Shows reminders and friction overlays when scrolling continues.
  • Helps perform a back action when you choose to leave.
  • Optionally attempts one pause gesture if you enable auto-pause.

What Drift does not upload

  • Short-video page text or page content.
  • Chat content, typed input, or password content.
  • Your local rules as ad-targeting data.
